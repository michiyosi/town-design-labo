## 3. 決まっていること（変えない）

- **Canvaは使わない。** 本人が使い慣れていないため
- 後半の芯は **「うちの店シート」を1枚書いて、それをAIに貼ることで毎回の説明をなくす**

## 5. 作り直しかた

```bash
cd seminar/sekio-dx-2026-09/deck
npm install                        # 初回だけ（pptxgenjs / docx / playwright）
node build-kouhan-full.js          # → ../DXマーケティング後半編.pptx（36枚）
node tools/build-daihon.js         # → ../石央商工会DXセミナー_後半_台本.docx
```

```bash
cd seminar/sekio-dx-2026-09
```

## 6. 環境の落とし穴（同じところで時間を溶かさないために）

クラウド版のClaude Codeで作業した場合、次でつまずきます。**先に対処してから始めてください。**

```bash
# LibreOffice に Impress / Writer が入っていない（pptx・docx を変換できない）
apt-get update -q && apt-get install -y -q libreoffice-impress libreoffice-writer

# 日本語フォントが IPAGothic しかない。游ゴシックに近づける
apt-get install -y -q fonts-noto-cjk
# さらに /etc/fonts/conf.d/ に「游ゴシック → Noto Sans CJK JP」の別名を置くと再現度が上がる

# pdftoppm が無い。PDFを画像にするなら python の pymupdf を使う
pip install pymupdf

# Playwright は入っているが解決パスが通っていない
NODE_PATH=/opt/node22/lib/node_modules node tools/fit-ai-character.js
# Chromium: /opt/pw-browsers/chromium-1194/chrome-linux/chrome
```
