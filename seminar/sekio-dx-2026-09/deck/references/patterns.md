# 元デッキの型と寸法

単位はインチ。A4横 10.83 × 7.5。元デッキ（前半編・全30枚）の XML から抽出した値。
`deck.js` の各関数がこの値を持っているので、通常はここを直接使わなくてよい。部品にない配置を組むときの参照用。

## 型の一覧と元デッキでの出現

| 型 | 元デッキ | deck.js |
|---|---|---|
| 表紙（ピンク一面＋白枠線） | slide1 | `cover` |
| プロフィール（写真＋項目） | slide2, 3 | 部品なし。`card` + `body` + `addImage` |
| 見出し＋本文の説明 | slide4 | `card` + `body` |
| ステップの流れ（矢印の上にチップ） | slide5 | `flowRow` |
| テーマ提示（ピンク太字・中央） | slide6, 8, 12, 15, 17, 18 | `card` + `centerStatement` |
| 分析サイクル（矢印文字） | slide7 | `centerStatement` に「投稿⇒数字⇒仮説⇒改善」 |
| チェック項目（薄ピンクパネル＋スクショ） | slide9 | `card` + `pinkPanel` + `body` + `addImage` |
| 手順（①②③＋スクショ） | slide10 | `card` + `numberedPink`(fontSize 18) + `addImage` |

| ワークシート（白・罫線） | slide29, 30 | `worksheet` |

## 寸法

### 表紙（slide1）
- 背景 `D15881`
- 主催名：(0.48, 1.37) 3.53×0.44、20pt 太字 白
- 白枠：(0.34, 2.17) 10.16×2.77、塗りなし、線 白 2.75pt（34925 EMU）
- 枠内テキスト：セミナー名 24pt / サブタイトル 14pt / 【前半】… 24〜28pt、すべて白太字中央
- 日付：(3.45, 5.12) 3.93×0.4、16pt 白太字中央
- ロゴ：(3.63, 5.52) 3.57×0.69

### 本文スライドの土台（slide6〜27）
- 背景 `E2EFD9`（テーマ accent6 `70AD47` の lumMod 20% / lumOff 80%）
- 白カード：(0.37, 0.55) 10.1×6.47、roundRect adj 4136（角はごく小さい）、線なし
- ロゴ：(9.11, 0.20) 1.36×0.35
- スライド番号：右下、12pt
- eyebrow：(0.60, 0.85) 8.76×0.5、24pt ピンク太字
- 大見出し：(0.60, 1.64) 9.36×0.77、40pt ピンク太字

### テーマ提示（slide6）
- テキスト：(0.37, 1.0) 10.1×7.3 の中に 36pt ピンク太字、中央、行間ゆったり

### チップ（slide13, 19）
- 1.47×0.78、roundRect（既定の丸み）、塗り `BDD7EE`（accent5 lumMod 40% / lumOff 60%）、線 同色
- 黒太字 12〜14pt 中央
- slide13 の横並び：x = 1.01, 2.72, 4.43, 6.18, 7.94（間隔 1.71〜1.76）、y = 4.12
- 件数の小テキスト：チップの下 (x+0.4, y+0.86) 0.65×0.37、16pt 太字

### 3列グリッド（slide19）
- 列 x = 1.48, 4.18, 7.00
- ラベルバー：(x−0.09, 1.24) 1.75×0.43、角なし、ピンク／濃青 `5B9BD5`／ピンク、白文字
- 行 y = 1.79, 2.95, 4.11, 5.32（間隔 1.16）
- 3列目のチップは幅を 1.6〜2.8 に伸ばしてよい
- 矢印：二等辺三角形 0.28×0.24、右向き（rotate 90）、塗り `70AD47`、チップ間の中央

### 表（slide23）
- (0.76, 1.9) 9.34×3.6
- ヘッダー行 塗り `F5BDD6`、黒太字中央
- 本文 12pt、罫線グレー

### 実践（slide26）
- テキスト：(0.82, 2.02) 9.24×3.87、32pt ピンク太字、① ② ③ 各段落

### まとめ（slide27）
- eyebrow「前半のまとめ」：(0.97, 1.18) 24pt
- 本文：(0.76, 1.89) 9.48×4.34、36pt ピンク太字、「☐ 」始まり

### 締め（slide28）
- 背景 `D15881`
- 白枠：(1.03, 3.91) 7.23×1.65、塗りなし 白線
- テキスト：32pt 白太字
- ロゴ：(3.76, 6.37) 2.65×0.69

### ワークシート（slide29, 30）
- 白背景、カードなし、ロゴなし
- タイトル行：(0.21, 0.4) 10.63×0.37、16pt 太字「◯◯ ワークシート　　事業者名（　　）」
- 表：(0.21, 1.4) 10.42×2.94、左列は項目名（太字 14pt・薄グレー塗り）、右列は空欄＋薄い例文（10〜12pt グレー）
- 罫線 黒 0.75pt

## テーマ色（元ファイルの theme1.xml）
Office 既定のまま。accent1 `4472C4` / accent2 `ED7D31` / accent5 `5B9BD5` / accent6 `70AD47`。
ピンク `D15881` はテーマ色ではなく直接指定。
