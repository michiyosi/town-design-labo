# NG表現リスト

> [!summary] 要点
> Claude Code に文章を書かせるとき、使ってほしくない表現の一覧。
> 「その表現はやめて」と言われたら、ここに 1 行追加する。

## 一覧

| 表現 | 理由 | 言い換え |
|---|---|---|
| いかがでしょうか | AI 特有の過剰な丁寧さ | 文末を言い切りにする |
| ぜひご活用ください | 定型で空疎 | 削除するか具体的な使い方を書く |
| 〜することが可能です | 冗長 | 〜できます |
