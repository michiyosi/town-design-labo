# brain/ — クラウド環境用の「第2の脳」

Claude Code on the web（クラウド）でこのリポジトリを開いたとき、
`/obsidian-memo` `/expression-rules` `/writing-knowledge` はここにメモを保存する。

ローカルの Obsidian 保管庫で同じスキルを使うと、保管庫の直下に保存される（`brain/` は使わない）。
判定ルールは各スキルの SKILL.md「保存先（保管庫）の決め方」を参照。

> [!warning] 公開範囲
> このリポジトリは GitHub Pages で公開されているため、ここに置いたファイルは URL を知っていれば誰でも見られる。
> 個人情報・パスワード・未公開の数字は書かないこと。機密を扱うなら別の非公開リポジトリに移す。

## ローカル保管庫と同期したいとき

ローカルで `brain/` の中身を保管庫にコピーする（または逆）。Obsidian で `brain/` を保管庫として開いても動く。
